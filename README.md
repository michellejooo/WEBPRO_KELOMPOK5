# WEBPRO_KELOMPOK5
EVENT.KITA adalah platform berbasis website yang dirancang untuk membantu mahasiswa menemukan, mencari, dan mengelola berbagai acara kampus. Website ini menyediakan fitur pencarian acara, filter kategori, detail acara, kalender kegiatan, serta pengelolaan acara bagi penyelenggara.  **Teknologi:** HTML, CSS, Bootstrap 5, dan JavaScript.
